# MINI-BASKETBALL SCOREBOOK

ミニバスケットボールの試合進行をブラウザだけで記録できるスコアブックです。

## 機能

- 選手を起点にした成功・失敗シュート、リバウンド、アシストなどの記録
- 4クォーター（各6分）のゲームクロック管理
- ポゼッション表示
- 最大15名の選手登録、個人／クォーター別チームファウルの自動集計
- スタッツ、公式スコアシート、ランニングスコア、プレイ・バイ・プレイの自動生成
- すべての集計に連動する UNDO / REDO
- Web Speech API 対応ブラウザでの日本語音声入力
- A4スコアシートの印刷／PDF保存
- ブラウザのローカルストレージへの自動保存
- iPad横向きを中心としたタブレット／スマートフォン対応

得点やスタッツは重複保存せず、時系列の試合イベントからすべての表示を導出します。

## 起動方法

追加のパッケージは不要です。`index.html` をブラウザで開くか、ローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` にアクセスします。
